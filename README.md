
# Customer Churn Prediction AI

An end-to-end Machine Learning project that predicts whether a customer is likely to churn based on customer information.

## Project Overview

Customer churn means a customer stops using a company's service.

This project uses Machine Learning to classify customers into:

- 0 → Customer likely to stay
- 1 → Customer likely to churn

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Joblib
- Google Colab

## Features

The model uses:

- Age
- Tenure
- Monthly Charges
- Contract Type
- Internet Service
